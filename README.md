# Corporate Sustainability Reporting & ESG Analytics

Independent student portfolio project using synthetic data.

## Data lineage
`01_environmental_data_raw.csv` → `02_validation_log.csv` → `03_environmental_data_clean.csv` → `04_powerbi_model_input.csv` → Power BI dashboard

## Project facts
- 6 simulated manufacturing sites
- 2023-2025 monthly reporting
- 216 expected unique site-month submissions
- 219 raw rows due to duplicate submissions
- 15 documented data-quality issues
- 216 validated clean records

## 2025 results
- Total Scope 1 + 2 GHG: 47,613.3 tCO2e
- GHG change vs 2024: -10.1%
- Renewable electricity share: 66.8%
- Recycling rate: 85.3%
- Water withdrawal: 3,142,731 m3

All company and operational data are synthetic. The ESRS mapping is educational and not a compliance assessment.
